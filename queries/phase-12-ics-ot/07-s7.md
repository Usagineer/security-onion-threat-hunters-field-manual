# ICS/OT — S7 / S7comm

## What this does

Reviews ICS/OT communications and impact-related activity involving S7. Use the results with the surrounding host, user, time, and network context before escalating.

```
event.dataset:zeek.conn AND destination.port:102 | groupby source.ip destination.ip
```

```
event.dataset:zeek.s7comm | groupby source.ip destination.ip s7comm.function
```

```
event.dataset:zeek.s7comm AND s7comm.function:(*Download* OR *Upload* OR *PLC Stop* OR *PLC Start*) | groupby source.ip destination.ip
```
